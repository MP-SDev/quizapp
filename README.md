Hello to the Unicorn Quiz! Here you can answer questions about unicorns, collect points and find out what title you can earn with your knowledge. The answers are presented as child-friendly pictures and there’s some leeway whilst playing, but don’t let the unicorn catch you cheating – otherwise it’ll stick its tongue out at you!
This quiz was created using HTML elements from Bootstrap. The answer images are AI-generated. The questions and answers can be customised via the object.
Have fun trying it out, using it and customising it
